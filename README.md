# Samadhan Connect 🇮🇳
### Digital Innovation & Civic Problem-Solving Platform for Jharkhand (Smart India Hackathon 2026)

**Samadhan Connect** is a digital platform designed to crowdsource societal challenges across Jharkhand and facilitate collaborative problem-solving by uniting **Citizens**, **Students & Researchers**, **Universities**, **Industry CSR Partners**, and **Government Officials**.

---

## 🌟 Key Features

- **Universal 1-Click Persona Switcher**: Top demo banner allowing instant 1-click switching between all 6 stakeholder roles:
  - **Citizen** (*Report & track local challenges*)
  - **Student / Researcher** (*Propose solutions & build prototypes*)
  - **University Coordinator** (*Mentor student teams & manage R&D cells*)
  - **Industry Mentor** (*Sponsor projects via CSR & evaluate milestones*)
  - **Government Official** (*Verify problems & monitor pilot deployments*)
  - **Platform Administrator** (*Statewide telemetry & moderation*)
- **6-Step Problem Reporting Wizard**: Multi-step grievance & challenge reporting with 1-click demo samples, photo upload dropzones, and `canvas-confetti` celebrations.
- **Explore Challenges Marketplace**: Searchable discovery marketplace with category, 24-district, and urgency filters.
- **Project Workspaces**: 5-phase visual lifecycle tracker (*Research → Prototype → Testing → Implementation → Completed*), sprint task Kanban boards, milestone roadmaps, activity streams, and mentor review ratings.
- **Directories & Matchmaking**:
  - *University Directory* with innovation portfolios.
  - *Industry Directory* with CSR mentorship requests.
  - *Collaboration Hub* for student team formation & recruitment.
- **1-to-1 Split-Screen Messaging**: Real-time communication channels between citizens, students, mentors, and government coordinators.
- **Notification Drawer**: Centralized alerts for verification updates and milestone achievements.

---

## 🛠️ Technology Stack

- **Frontend**: React 19, Vite 8, React Router v6
- **Styling**: Tailwind CSS v4, Lucide React Icons
- **Design System**: Forest Green (`#064e3b`), Warm Amber (`#d97706`), Google Fonts (*Outfit* & *Plus Jakarta Sans*)
- **State & Storage**: React Context API with persistent LocalStorage

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/hackathonmain404-beep/sih.git
cd sih
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

The application will be live at `http://localhost:5173`.

### 4. Production Build
```bash
npm run build
```
